 Machine-learning

A small collection of Python scripts exploring machine learning and programming fundamentals.

## Contents

- **boolean.py** — Machine learning code exploring boolean logic concepts.
- **boolean_2.py** — Updated/extended version of the boolean logic script.
- **gymmembership.py** — Script modeling a gym membership scenario.

## Getting Started

### Prerequisites

- Python 3.x installed

### Running the scripts

Clone the repository and run any script directly:

```bash
git clone https://github.com/emmanuelnyamorah-glitch/Machine-learning.git
cd Machine-learning
python3 <script_name>.py
```

Replace `<script_name>.py` with the file you want to run, e.g. `boolean.py`.

This repository is used for learning and experimenting with machine learning concepts and basic Python programming exercises.
